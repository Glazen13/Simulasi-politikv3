# Hingga ke Jannah

Game simulasi kehidupan suami isteri.

## Cara Main

1. Buka `index.html` dalam browser
2. Pilih mod (Suami / Isteri)
3. Taip nama & panggilan
4. Pilih personaliti pasangan
5. Pilih titik mula
6. Setup kewangan
7. Main!
